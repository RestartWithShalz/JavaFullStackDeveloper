Question :
What does @SpringBootApplication annotation does?

Answer:
@SpringBootApplication tells the SpringBoot how to configure the application. It combines annotations @Configuration, @EnableAutoConfiguration and @ComponentScan. @Configuration annotation tells this class provides all the Spring Bean definations, @EnableAutoConfiguration tells to see all configurations in the classpath, environment and configure the components automatically, @ComponentScan scans all the relevant packages for components such as @controller, @service, @repository and @component.

Question:
Why is constructor injection preferred over creating ProductService directly with new ProductService() inside OrderService?

Answer:
Constructor Injection is preferred because it makes dependencies explicit, supports loose coupling and easy Unit Testing. It also allows alll the required dependencies to be provided at the time of object creation. Spring manages and injects the dependeancy instead of the class creating it with new.

Question:
Does save() always inserts?

Answer:
save() is used for both creating and updating entities. For new enetity it results in an INSERT, while for an existing entity it result in an UPDATE depending on the entity's persistence state and identifier.


Question:
Why does our controller return List<Product> instead of returning a JSON string manually, such as: return "[{\"id\":1,\"name\":\"Laptop\"}]";

Answer:
List<Product> is returned because the application works with Java Objects, not manually constructed JSON strings. Spring Boot uses Jackson to automatically serialize the product objects into JSON when sending HTTP response. This way, it is cleaner, type-safe and easier to maintain than manually building JSON strings.

Qusetion:
What is the difference between @Controller and @RestController in Spring?

Answer:
@Controller is used for traditional MVC applications where a controller method may return a view name. @RestController is used for REST APIs, it combines @controller and @ResponseBody, so the method return value is written directly into HTTP response body.Spring Jackson converts the response or list into JSON.

Question:
What is the difference between @RequestBody and @PathVariable?

Answer:
@RequestBody is used to bind the data from HTTP request body usually JSON to a JAVA object. It is commonly used with POST, PUT and PATCH requests.

@PathVariable is used to extract a value from the URL path and bind it to the method parameter. It is commonly used when we need to identify a specific resource.

Question:
What is the difference between JPA and Hibernate?

Answer:
JPA is specification that defines the standard for ORM and persistence in JAVA,
while Hibernate is the ORM framework that provides an implentation of that specification.
