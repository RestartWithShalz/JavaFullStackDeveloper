Spring Data JPA sits on top of JPA. 
It makes repository/database access much easier.


For eg:

when we write,

public interface ProductRepository extends JPARepository<Product, Long> {
}

we get methods like: 

findAll(), finfById(), save(), deleteById(), existsById()

without implementing all those database operations ourselves.


save() : productRepository.save(product);

Spring data JPA decides whether this is an INSERT or UPDATE based on the entity's identity/state.
